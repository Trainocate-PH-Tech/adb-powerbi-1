# Possible Visuals for ORM

| Use case                             | Recommended visual               | Why                                            |
| ------------------------------------ | -------------------------------- | ---------------------------------------------- |
| Total Outstanding Exposure           | **Card**                         | Best for a single KPI such as `$1.95B`         |
| Total Commitment Amount              | **Card**                         | Another headline KPI                           |
| Exposure by Instrument               | **Clustered column chart**       | Easy comparison of Debt, Equity, Guarantee     |
| Exposure vs Commitment by Instrument | **Clustered column chart**       | Shows both measures side by side               |
| Top 5 Countries by Exposure          | **Horizontal bar chart**         | Best for ranked categorical data               |
| Exposure by Country                  | **Bar chart**                    | Easy to sort descending                        |
| Exposure over time                   | **Line chart**                   | Best for Nov → Dec or longer month-end trends  |
| Exposure by Risk Rating              | **Column chart**                 | Shows concentration across ratings             |
| Exposure by Sector                   | **Bar chart**                    | Useful for portfolio concentration             |
| Exposure by Product Type             | **Donut chart** or **bar chart** | Good introductory composition visual           |
| Detailed portfolio records           | **Table**                        | Lets users inspect facilities/obligors         |
| Country + Instrument drill-down      | **Matrix**                       | Good introduction to multidimensional analysis |
